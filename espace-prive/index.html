🎯 Objectif de la formation

Apprendre à utiliser Claude Code depuis un terminal pour comprendre un projet, créer une structure, générer ou modifier des fichiers, corriger des erreurs, écrire des tests, documenter le travail et suivre l'avancement d'un projet.

✅ Pré-requis

  • Un ordinateur récent et une connexion Internet
  • Un compte Claude compatible avec Claude Code
  • Un terminal ou une invite de commande
  • Un projet à créer ou un dossier de travail
  • Aucune expérience avancée en programmation n'est exigée
Module 1 Comprendre l'IA et Claude Code
  • Intelligence artificielle générative
  • Modèle de langage, prompt et contexte
  • Différence entre conversation et agent de développement
  • Notions de fichier, dossier, projet, code source et test
  • Importance des sauvegardes et de la vérification humaine

Module 1 Comprendre le connectome

Un connectome représente les connexions entre les neurones d'un système nerveux. On peut le comparer à une carte : les neurones sont les villes, les synapses sont les routes et les flèches indiquent le sens de circulation. Cette carte ne décrit cependant pas toute l'activité biologique du cerveau.

G = (V, E)

V  : ensemble des neurones
E  : ensemble des connexions
Wij : poids ou importance d'une connexion entre i et j
🎯 Activité — Le réseau humain

Distribuez des rôles : neurones sensoriels, neurones intermédiaires et neurones moteurs. Faites circuler une carte « obstacle à gauche » et observez quelle sortie est activée. Cette activité rend concrète la propagation de l'information dans un connectome.

Les neurones afférents reçoivent les informations sensorielles, les neurones intrinsèques traitent et transmettent les informations, et les neurones efférents produisent les commandes motrices.

Module 5 Projet pédagogique simplifié

Projet proposé : construire un mini-agent inspiré d'un circuit neuronal de mouche, capable de choisir entre avancer, tourner à gauche ou tourner à droite dans un environnement simple.

Entrées : distance devant l'agent, obstacle à gauche, obstacle à droite, direction cible.
Sorties : avancer, tourner à gauche, tourner à droite ou s'arrêter.

  • Créer le graphe
  • Définir les connexions
  • Envoyer une observation
  • Propager l'information
  • Produire une action
  • Simuler le déplacement
  • Mesurer la réussite
  • Améliorer les poids
observation = lire_observation()
signal_sensoriel = encoder(observation)
message = matrice_connectome @ etat_neuronal
etat_neuronal = mise_a_jour(message, signal_sensoriel)
action = decoder(etat_neuronal)
environnement.executer(action)
recompense = environnement.calculer_recompense()
🎯 Activité — Le connectome en Lego

Construisez un mini-réseau avec des blocs ou des cartes : trois entrées, deux neurones de décision et trois sorties. Changez les connexions et comparez les comportements obtenus : l'architecture influence directement les actions produites.

Module 6 Apprentissage

L'apprentissage par imitation reproduit les actions d'un contrôleur existant. L'apprentissage par renforcement fonctionne par cycles : observation, action, réaction de l'environnement, récompense et ajustement du comportement.

Exemple : une trajectoire stable reçoit une récompense positive, tandis qu'une collision ou une perte d'équilibre entraîne une pénalité.

🎯 Activité — Imitation ou récompense ?

Scénario 1 : le modèle observe un expert et reproduit ses actions → c'est l'imitation. Scénario 2 : il essaie des actions et reçoit une récompense → c'est le renforcement. Testez la jauge ci-dessous pour ressentir l'effet d'une récompense ou d'une pénalité.

Module 7 Visualisation et expérimentation

La visualisation aide à repérer les neurones, les groupes fonctionnels, les connexions principales et la circulation de l'information. Elle ne constitue pas à elle seule une preuve scientifique.

Chaque expérience doit préciser une question, une hypothèse, une configuration, une mesure et une conclusion.

ModèleStructure
AGraphe inspiré du connectome
BGraphe aléatoire
CRéseau dense classique

Mesures possibles : temps d'apprentissage, erreur de trajectoire, stabilité du mouvement, nombre d'épisodes réussis, mémoire utilisée, temps de calcul.

Module 8 Limites
  • Un connectome décrit une structure, pas toute l'activité cérébrale
  • Les données biologiques peuvent être incomplètes ou évoluer
  • Une simulation n'est pas un cerveau réel
  • Les performances dépendent des données et de l'entraînement
  • La puissance informatique nécessaire peut être importante
  • Le terme Fly Connectome doit être défini précisément selon le projet
