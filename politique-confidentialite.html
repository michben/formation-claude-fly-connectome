Politique de confidentialité et cookies

Dernière mise à jour : 18/09/2026

🍪 Qu'est-ce qu'on stocke, et pourquoi ?

Ce site utilise le stockage local de votre navigateur (localStorage) plutôt que des cookies publicitaires classiques. Rien de ce qui suit n'est partagé avec des régies publicitaires ni utilisé pour vous suivre sur d'autres sites.

Donnée stockéeÀ quoi ça sert
Code d'accès à l'espace formationÉviter de ressaisir votre code à chaque visite
Réponses aux quiz et aux fichesNe pas perdre votre progression entre deux visites
Identifiant de conversation (chat)Retrouver l'historique de vos échanges avec l'agent et michben
Choix cookies (accepté/refusé)Ne pas réafficher la bannière à chaque page

🔗 Services externes

Certains boutons du site vous redirigent vers des services tiers, qui ont leurs propres règles de confidentialité :

  • Stripe (paiement) — politique de confidentialité Stripe
  • Calendly (réservation de créneaux) — politique de confidentialité Calendly

💬 Chat et messages

Si vous écrivez à l'agent de conversation, votre message et la réponse (automatique ou de michben) sont conservés pour assurer le suivi de votre demande. Ne partagez jamais de mot de passe, de clé API ou de coordonnées bancaires dans le chat — l'agent est d'ailleurs configuré pour refuser ce type d'information.

🗑️ Comment supprimer ces données ?

Vous pouvez à tout moment effacer ces données depuis les paramètres de votre navigateur (données de site / stockage local), ou en cliquant sur « Se déconnecter » dans l'espace formation. Pour une demande de suppression complète côté serveur (messages de chat, résultats de quiz), contactez michben via le chat du site.

✋ Vos choix

En refusant les cookies via la bannière, seules les données strictement nécessaires au fonctionnement du site que vous utilisez (par exemple votre code d'accès une fois saisi) continuent d'être enregistrées localement ; le reste n'est pas activé.
